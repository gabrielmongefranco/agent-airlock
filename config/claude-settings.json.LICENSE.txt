Summary: Default Claude Code user settings copied into the airlock on first
         start. Turns on the inner Bash sandbox in nested mode with its
         filesystem layer off, because the container already limits writes
         to ~/git and the home volume. Makes all of /home/agent/git a working
         directory, lists commands that must run at container level (dev
         servers, Playwright, npm and pipx installs), seeds the outbound
         domain allowlist, and hides API keys from sandboxed shell commands.
